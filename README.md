# Vélora - Timeless Elegance Fashion Landing Page

A luxury fashion e-commerce & brand landing page built from scratch for WordPress, inspired by high-fashion editorial aesthetics and built with **Vite** and **Tailwind CSS**.

---

## ✨ Zero Page Builder Dependency
- **100% Native WordPress Customization**: Edit every section, title, price, benefit, product, testimonial, and image directly from the WordPress Admin Dashboard.
- **No Elementor required**
- **No Gutenberg page builder required**

## 🛠️ Dashboard Customization Options

### 1. 🛍️ Native Product Uploads (No WooCommerce Needed!)
Go to **Products** in the WordPress admin menu:
- **Add New Product**:
  - Title, Product Description, and Excerpt.
  - **Product Pricing & Details**:
    - Regular Price (e.g. `$ 420.00`)
    - Sale Price (e.g. `$ 380.00`)
    - Department / Subtitle (e.g. `Women`, `Men`, `Accessories`)
    - Badge Tag (e.g. `New`, `Bestseller`, `Exclusive`, `Signature`)
  - **Product Categories (`velora_category`)**: Assign to categories like `Dresses`, `Suits`, `Accessories`, etc. The category filters on the homepage update dynamically!
  - **Featured Image**: Upload high-resolution product photos.
- **Dedicated Single Product Page**: Automatically formatted with luxury gallery, size selectors, add to bag, customer review stars, and value props.

---

### 2. 🎨 Typography, Colors & Dimensions (Font & Height / Weight Controls)
Available in both **Appearance > Customize** and **Appearance > Vélora Theme Options**:

- **🔤 Typography & Fonts**:
  - **Heading Font Family**: Cormorant Garamond, Cinzel, Playfair Display, Bodoni Moda, Prata, Marcellus, Syne, Montserrat, Inter, Plus Jakarta Sans.
  - **Body Font Family**: Plus Jakarta Sans, Inter, Montserrat, Lato, Poppins, Outfit.
  - **Heading Font Weight**: Light (300), Regular (400), Medium (500), Semi-Bold (600), Bold (700).
  - **Body Font Weight**: Light (300), Regular (400), Medium (500).
  - **Base Font Size**: e.g., `15px`, `16px`.
- **🎨 Colors & Palette**:
  - **Accent Gold Color** (default: `#c5a880`)
  - **Accent Hover Color** (default: `#a98b64`)
  - **Dark / Black Background** (default: `#0c0c0c`)
  - **Light Cream Background** (default: `#faf9f5`)
  - **Heading Text Color** (default: `#0c0c0c`)
  - **Body Text Color** (default: `#4a4a4a`)
- **📐 Layout, Heights & Dimensions**:
  - **Hero Minimum Height**: e.g., `640px`, `700px`, `80vh`, `100vh`.
  - **Container Max Width**: e.g., `1280px`, `1400px`, `1600px`.
  - **Product Card Aspect Ratio**: `4/5` (Luxury Portrait), `3/4` (Editorial), `1/1` (Square), `2/3` (Tall).
  - **Section Vertical Padding**: e.g., `80px`, `100px`.

---

### 3. 🖼️ Direct Image Uploading (Media Library Modal)
- Upload all hero banners, category images, editorial cards, story photos, and avatars directly through the **native WordPress Media Library uploader** (`wp.media`) with instant thumbnail preview and remove buttons.

---

### 4. Live Customizer vs. Theme Options
- **Live Customizer**: Navigate to **Appearance > Customize > Vélora Theme Options** to preview typography, colors, and layout live in real-time.
- **Dedicated Admin Page**: Navigate to **Appearance > Vélora Theme Options** for full tabbed management with media uploaders and color pickers.
